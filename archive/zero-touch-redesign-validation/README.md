# Zero-Touch Redesign Validation Archive

This directory preserves the completed zero-touch README redesign validation
materials that informed the current agent skills and workflow checks.

These files are archived for provenance and future re-analysis. They are not
part of the normal one-button game generation workflow.

## Contents

- `analysis.md`: comparison of zero-touch outputs and human-revised versions,
  with extracted design and prompt rules.
- `validation-plan.md`: original A/B validation plan and reporting template.
- `specs/`: control and treatment README inputs used during validation.
- `reports/`: per-game validation reports and the Phase 1 summary.

Current workflow rules derived from this work live under `.agents/skills/` and
`scripts/check_generated_game.js`.
